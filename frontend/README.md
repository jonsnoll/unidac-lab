# Frontend do unidac-lab

Interface web do unidac-lab.

Tecnologias principais:

- React
- React Flow
- Vite

Responsabilidades:

- editor visual;
- catálogo;
- propriedades;
- Apply Plan;
- lifecycle;
- console;
- Packet Capture;
- controles de rede.

Para build:

npm run build

Na v0.1.0 o frontend é executado através do Docker Compose.
